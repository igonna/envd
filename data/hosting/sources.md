# Hosting Catalog Sources

This catalog is a conservative starting point, not a guarantee that a provider
is reachable, safe, or currently accepting a specific payment method.

Maintenance rules:

- Keep entries transparent and inspectable.
- Prefer provider and ASN diversity over one globally "best" provider.
- Mark stale entries instead of silently deleting them.
- Verify homepage, signup URL, API URL, regions, minimum plan, payments, ASN,
  and country before raising confidence.
- Treat local private overlays as user-owned data; envd must not upload them.

The first built-in catalog intentionally stays small. Broader provider research
and signed catalog updates are separate work.
